=========================
Ecommerce First Last Name
=========================

This module Ecommerce First Last Name module is a part of Ecommerce and used in
website to modify first name and last name of current user based on company type

**Table of contents**

.. contents::
   :local:

Usage
=====

To check functionality of this module,

1. Go to "Website" > "Shop" > select an item > "Add to cart" button > "Order overview" > "Checkout" button > Delivery
2. You will see two edit boxes, which are "First Name" and "Last Name"
3. Toggle between "Private Customer" and "Business Customer" radio buttons
4. Notice how the "Company Name" and "TIN / VAT" fields appear and hide based on selection
