=========================
Ecommerce First Last Name
=========================

This module is used in website and during checkout shows two fields, first name and last name,
instead of just one name field.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Go to "Website" > "Shop" > select an item > "Add to cart" button > "Order overview" > "Checkout" button > Delivery
2. You will see two edit boxes, which are "First Name" and "Last Name"
3. Toggle between "Private Customer" and "Business Customer" radio buttons and notice how the "Company Name" and
  "TIN / VAT" fields appear and hide based on selection
