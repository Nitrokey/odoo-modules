This module automatically disables password-based login for users who have OAuth authentication enabled.

**Table of contents**

.. contents::
   :local:

Features
========

* Automatically detects users with OAuth authentication enabled
* Prevents password-based login for OAuth-enabled users
* Maintains API key authentication functionality
* Adds a visual indicator in the user interface showing when password login is disabled

How It Works
============

The module works by:

1. Computing a ``disable_password_login`` field that checks if a user has an OAuth access token
2. Overriding the ``_crypt_context()`` method to raise an ``AccessDenied`` exception when:
   
   * The user has OAuth authentication enabled (``oauth_access_token`` is present)
   * A password-based login is attempted

3. OAuth and API key authentication methods continue to work normally

This ensures that once a user has authenticated via OAuth, they cannot bypass that security by using a password.

Usage
=====

To use this module:

1. Install the module
2. Configure OAuth providers in Odoo (Settings > Users & Companies > OAuth Providers)
3. Users who authenticate via OAuth will automatically have password login disabled
4. The user form will show "Password Login Disabled" for affected users
